<objective>
Fix audit #4, #9 and #12. The scan stats a file AFTER hashing, so an edit in between records the new mtime with the old hash and the change is skipped forever. Each changed file is then hashed a second time inside `_upload_single_file`. The post-upload "verification" compares the md5 metadata the code just wrote against itself, so it proves nothing.
</objective>
